# Shhh Builder 1.0.0

Initial release of Shhh Builder for Minecraft 26.3 Fabric.

Shhh Builder is a clean, client-side schematic viewer and building assistant. It gives you clear visual guidance in your world without cluttering the screen or complicating the building process.

---

### Features in this release

- **Hologram & Wireframe Previews**: View schematics in-world with translucent block models or clean wireframes.
- **Occlusion Culling**: Fully enclosed blocks are culled automatically to maintain high performance on larger builds.
- **Materials Checklist (`K`)**: Complete breakdown of required blocks, live inventory comparison, shulker box counting, and a one-click copy button for shopping lists.
- **Progress Tracking**: Missing counts update in real time as you place blocks in the world.
- **Pick-Block Integration**: Middle-click any ghost block to quickly equip or select it from your hotbar or inventory.
- **Layer Slicing (`M`, `[`, `]`)**: Switch between All Layers, Single Layer, and Up To modes for step-by-step construction.
- **In-World Positioning**: Rotate (`R`), mirror (`Z`), and nudge with arrow keys without returning to the menu.
- **Interactive In-Game Tutorial**: A 7-step guide explaining every feature (`/shhhbuilder tutorial`).
- **Zero Mixins**: Built entirely on standard Fabric API events for full compatibility with performance mods like Sodium, Iris, and Lithium.
- **Fair-Play**: Purely client-side with no network packets sent and no automated block placement.
